# مصادر الحديث والشاملة: التقييم وطريقة الاستخدام

## سجل حديث واحد في سَنَد

في «الباحث الآلي» اختر كتابًا عربيًا ورقم السجل واضغط «عرض سجل واحد». بعد الموافقة يطلب المتصفح (وفي Windows متصفح الواجهة المحلية) سجلًا واحدًا من واجهة GitHub العامة لمستودع [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api)، عند الإصدار المثبّت `df57907be35291c91ad6a6691180e22ca9920784`. لا يجلب كتبًا كاملة ولا يتيح البحث النصي أو البحث بالجزء والصفحة. يدعم حاليًا أرقام السجلات الصحيحة الموجبة للبخاري ومسلم وأبي داود والترمذي والنسائي وابن ماجه ومالك؛ الأرقام الكسرية غير مدعومة. يدعم إدخال الأرقام العربية والهندية والعالمية.

- يصلك النص كما ورد، مع الرقم العربي ومرجع القسم/الحديث إن وُجدا، والأحكام المنقولة مع أسماء من نسبها المورد إليهم بلغتها الأصلية. لا يتحقق سَنَد من نسبة حكم إلى صاحبه أو من النص أو صحته، ولا يعني غياب الحكم الصحة أو الضعف. لا تفترض أن الرقم أو اللفظ يطابق طبعة مطبوعة؛ راجع طبعتك والتخريج والسياق والروايات.
- قد يكون السجل فارغًا (مثل مسلم 1 في الإصدار الذي فُحص)، أو غير موجود، أو يتعذر الاتصال والخدمة أو تحظر الطلبات؛ يميز سَنَد هذه الحالات ولا يستنتج منها عدم وجود الحديث. رابط السجل مرتبط بالإصدار لا بالفرع المتغير، لكن استمرار GitHub وإتاحته غير مضمونين. تفرض GitHub حدودًا على الاستخدام، وقد يشترك مستخدمون في حد شبكة واحدة.
- «إضافة النص والمصدر للمراجعة» اختيار منفصل يطلب موافقة أخرى، ثم يضيف النص والأحكام المنقولة والرابط وتاريخ الاطلاع إلى **ملاحظات مصدر** محلي. لا ينشئ ادعاءً ولا يصنف الحديث صحيحًا أو ضعيفًا. احفظ المشروع للاحتفاظ بالإضافة. قد يظهر النص في التقرير أو النسخة الاحتياطية؛ راجع الحقوق قبل تخزينه أو إعادة نشره. الإضافة إلى المشروع ليست تحققًا بشريًا.
- يرسل الطلب إلى GitHub اختيار الكتاب والرقم، وترى GitHub عنوان IP ومعلومات الاتصال المعتادة. لا تُرسل ملفاتك أو مشروعك. لا يستخدم سَنَد مفتاحًا أو حسابًا في هذا الطلب. سياسة أمن Windows تسمح بالاتصال بمسار بيانات هذه الواجهة فقط؛ لا يلغي البرنامج التحقق من شهادات TLS.
- يعلن المشروع Unlicense لعمله، لكن قائمة [المراجع](https://github.com/fawazahmed0/hadith-api/blob/df57907be35291c91ad6a6691180e22ca9920784/References.md) تضم مصادر متعددة، وفهرسه الذي فُحص لا يحدد مصدر طبعة البخاري العربية أو مؤلف بياناتها تحديدًا كافيًا. لا يثبت ذلك ملكية جميع النصوص والترجمات أو أحكام المحققين ولا حق إعادة نشرها. سَنَد لا يوزع نسخة من هذه البيانات داخله؛ يطلبها عند الاختيار. يلزم فحص الحقوق بحسب الاستخدام قبل النشر، خصوصًا التجاري.

## الاختبارات وحدودها

تختبر `tests/test_hadith_lookup.cjs` التحقق من الرقم والإصدار والحجم والاستجابات والأخطاء. وتختبر `tests/ui_local_hadith.py` في المتصفح والخادم المحلي استجابة اصطناعية: الموافقة، وحماية HTML، والحفظ، وعدم تكرار المصدر، وإخفاق الخدمة وتغيير المشروع أثناء الطلب. تُشغّل محاكاة الواجهة أيضًا على EXE في CI. `tests/live_local_hadith.py` تشخيص اختياري يطلب البخاري 1 الحقيقي من GitHub مرة في كل واجهة؛ تعذّر الخدمة لا يعني نجاح الميزة أو فشل النص، ولا يقيس دقة الحديث أو الحقوق.

في بيئة التطوير الحالية رفض Chromium شهادة شبكة الاختبار (`ERR_CERT_AUTHORITY_INVALID`). نجح التشخيص في الواجهتين مع `SANAD_TEST_IGNORE_CERT_ERRORS=1` **في اختبار Chromium فقط**؛ لا يغير الاختبار إعدادات التطبيق. نجح طلب مستقل باستخدام عميل النظام. لا يُعد هذا اختبارًا لاتصال TLS السليم في Chromium لدى المستخدم. يُشغَّل التشخيص في CI دون تعطيل التحقق من الشهادات ويُعد اختياريًا لأن الخدمة الخارجية قد لا تتاح.
