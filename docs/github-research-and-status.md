# حالة سَنَد وتقييم مشاريع GitHub

تاريخ الفحص: 7 نوفمبر 2026. الأعداد تقريبية ومتغيرة، والنجوم ليست دليلًا على الأمان أو جودة OCR أو صلاحية الرخصة لجميع الاستخدامات.

## أين وصل المشروع؟

سَنَد نسخة أولية تعمل في المتصفح وكتطبيق Windows محلي محمول. يمكن إنشاء مشاريع ومصادر وادعاءات ومقارنات، وحفظها محليًا، والبحث في ملفات PDF النصية وTXT وMD وفي ملفات متعددة وربط مقتطفات للمراجعة، مع نسخة احتياطية محدودة. البحث عبر الجهات الخارجية اختياري وتختلف إتاحة النصوص حسب كل خدمة. تنزيل مجموعة OpenITI الأساسية والبحث في نصوصها متاح في Windows بعد الموافقة، بحجم 2.86 GB ورخصة CC BY-NC-SA. يمكن استيراد ناتج MinerU منفصل لمادة مسموحة؛ لا يشغّل سَنَد MinerU بنفسه.

يدعم OCR المحلي حتى 300 صفحة PDF متتابعة في الدفعة ضمن حد الملف 20 ميبيبايت. بعد الموافقة يُحفظ الأصل والتقدم صفحةً بصفحة محليًا ويمكن الاستئناف يدويًا على نفس الجهاز والمتصفح والموقع، مع ربط الأصل بالنتيجة عند الإيقاف أو الاكتمال. لا يدخل سجل المهمة قيد التنفيذ في النسخة الاحتياطية، وقد يفقد التقدم عند مسح التخزين أو تلف الجهاز. اختبار الاستئناف لا يثبت دقة OCR أو القدرة على معالجة جميع الكتب. [الحدود والتقييم](ocr-recovery-and-evaluation.md).

اختُبرت المعالجة الفعلية دون اتصالات خارجية خلال OCR على PDF **اصطناعي** مصوّر من 12 صفحة، يضم نصًا عربيًا وآخر إنجليزيًا وصفحة فارغة، وكذلك الإيقاف والنتائج الجزئية والبحث في صفحة 12 واستعادة المشروع. هذا ليس قياسًا لجودة OCR على الكتب التاريخية أو المخطوطات. وفي اختبار سابق لصورة غلاف تاريخي عربي مزخرف، لم يُستخرج العنوان بصورة موثوقة. يبقى التحقق البشري إلزاميًا.

ما زال ناقصًا: لا وصول للنص الكامل من جميع الجهات أو تجاوز قيودها، ولا استئناف تلقائي دون تدخل المستخدم بعد تعطل المتصفح، ولا تشغيل نموذج لغوي مدمج مستقل؛ LM Studio/Qwen اختياري ومنفصل في Windows. البحث العميق الوكيلي، والتحقق التاريخي الآلي، وترجمة وسرد وإنتاج فيديو آلي ونشر، ليست وظائف مكتملة. البحث في بعض الجهات فهرسي فقط. اعتماد أي نص أو استشهاد يتطلب مراجعة بشرية وتراخيص المادة.

## الأمان والخصوصية

في 7 نوفمبر 2026 أظهر فحص قاعدة إرشادات GitHub إرشادات متعددة تنطبق على إصدار `pypdf==5.9.0` السابق، منها [تعليق مع ملف تالف](https://github.com/advisories/GHSA-5849-834g-hvw5) و[استهلاك ذاكرة عند تحليل شجرة الصفحات](https://github.com/advisories/GHSA-cggf-277g-3q54). حُدّث التثبيت إلى `pypdf==7.0.0`؛ ولم يُرجع استعلام القاعدة في ذلك التاريخ إرشادات منطبقة على هذا الإصدار. اختُبر ملف عينة من إرشاد التعليق وملفات PDF نصية ومشفرة، لكن ذلك لا يغطي جميع أنواع الملفات أو الثغرات. النسخ المحمولة القديمة لا تتحدث تلقائيًا؛ استبدل البرنامج بنسخة أحدث واحتفظ ببياناتك ونسختك الاحتياطية.

في التاريخ نفسه لم يُرجع البحث عن الحزم المحددة `pdfjs-dist@4.8.69` و`tesseract.js@6.0.1` و`tesseract.js-core@6.0.0` إرشادًا ينطبق عليها. هذا فحص محدود لقاعدة واحدة بتاريخ معين، **وليس تدقيقًا أمنيًا ولا ضمانًا لسلامة الملفات أو الاعتماديات**. يُستخدم PDF.js مع تعطيل eval في مسار OCR وحدود لحجم الملف والصورة؛ أبقِ التطبيق والمتصفح محدثين، ولا تفتح ملفات غير موثوقة. حد الحجم وعدد الصفحات ليسا حدًا للذاكرة أو الوقت: لا تعمل قراءة PDF في عملية معزولة بحد موارد، وقد يؤدي ملف معقد أو خبيث إلى تعطيل التطبيق أو استهلاك موارد الجهاز. رُوجعت تراخيص المكونات المضمّنة في `web/vendor`؛ لا تُرفع مستندات المستخدم الخاصة أو مفاتيحه إلى المستودع.

يمكن دراسة الشيفرة المفتوحة وصيغ الملفات والواجهات الموثقة واختبار التوافق، مع مراعاة التراخيص والشروط. لا تُستخدم الهندسة العكسية هنا لتجاوز التشفير أو الإعارة أو الحجب أو إخفاء الهوية أو انتهاك خصوصية المستخدم. لا يضمن أي مشروع توفر مصادر الجهات الأخرى أو صلاحية استخدامها.
