# سَنَد — تصور نظام البحث التاريخي

**الحالة:** رؤية ومتطلبات أولية للنقاش، وليست وصفًا لخصائص مكتملة.
**الأولوية:** بناء باحث آلي للتاريخ الإسلامي يكتشف المصادر والمواد، ويتتبع أماكنها، ويحاول الوصول والاستخراج المسموحين؛ ليس الهدف إنشاء مكتبة على المستخدم ملؤها. السيناريو والإنتاج مخرجات لاحقة تعتمد على البحث.

## الهدف والقرارات المتفق عليها

- اقتراح موضوعات لشخصيات وأحداث من التاريخ الإسلامي تصلح لسلسلة حلقات طويلة، مع إمكانية إدخال موضوع يدويًا.
- البحث عن المصادر القديمة والحديثة والبحوث والدراسات ذات الصلة بلغات متعددة، وتتبع المراجع للوصول إلى المواد صعبة الاكتشاف، ضمن ما تسمح به الخدمات وحقوق الوصول. البحث والاستخراج جزء أساسي من عمل البرنامج، وليس مجرد إدارة ملفات يضيفها المستخدم.
- دعم إضافة كتب وملفات المستخدم التي يحق له استخدامها محليًا، بما فيها المصادر المدفوعة أو المحمية المصرح له باستخدامها، دون تجاوز حماية أو قيود وصول.
- تحليل المعلومات وترتيبها وفق **خطين زمنيين مستقلين**: زمن الأحداث، وزمن المصادر والروايات والدراسات.
- النظام قائم بذاته ويعمل محليًا على Windows، والاتصال بالإنترنت لجلب البيانات اختياري أو مطلوب فقط للبحث الخارجي. Qwen عبر LM Studio اختياري ولا يتحكم بالبرنامج أو ملفاته.
- الميزانية المستهدفة بلا اشتراكات مدفوعة؛ الإنترنت والتخزين والوقت، ومصادر مغلقة قد تكون لها تكلفة مستقلة.
- الجمهور الأساسي عموم الناطقين بالعربية، مع اهتمام بترجمة إنجليزية لاحقًا.

## دور الباحث الآلي

يتلقى البرنامج موضوعًا أو يرشح موضوعًا، ويضع خطة بحث متعددة اللغات، ويبحث في الفهارس والمجموعات ومراجع المصادر المكتشفة حيث يسمح بذلك. يراجع تنويعات الأسماء، ويحدد السجلات المتكررة والطبعات المختلفة دون دمجها تلقائيًا على نحو يضيع اختلافاتها، ويرشح المواد ذات الصلة مع أسباب الترشيح وروابط الأدلة.

لكل مادة يحاول الانتقال من السجل إلى النص أو الصورة أو الوثيقة المتاحة عبر قنوات مسموحة، ثم يستخرج الجزء ذي الصلة ويحفظ موضعه وسياقه. يقدم تقريرًا منفصلًا للمواد التي لم يقرأها أو تعذر الحصول عليها، مع المؤسسة ورقم الحفظ وخيارات الطلب أو الاطلاع. لا يساوي العثور على فهرس قراءة المصدر، ولا ينسب اقتباسًا إلى نص لم يطلع عليه.

يخرج للمستخدم ملفًا بحثيًا يضم المراجع والمواضع والأحداث والتواريخ والروايات المتفقة والمختلفة والمواد المرئية وحالات الترخيص والثغرات. الاحتفاظ بالمادة أو حذفها أو تصديرها قرار للمستخدم وفق حقوقها؛ لا يلزم أن ينشئ المستخدم مكتبة كتب قبل بدء البحث.

ينفذ البرنامج الاستعلامات والاستخراج المنظم عبر خدمات وأدوات مسموحة دون اشتراط نموذج. يمكن أن يساعد Qwen المحلي اختياريًا في تنويع المصطلحات وتحليل نصوص وصل إليها البرنامج، لكن قدراته وحدها لا تضمن اكتشاف كل المصادر أو صحة النتائج. لا يعمل البرنامج على تجاوز الاشتراكات أو الحماية، ولا يرسل ملفات خاصة لخدمات خارجية دون موافقة صريحة.

## تجربة البحث المطلوبة

1. **اختيار سؤال:** يختار المستخدم مقترحًا له سبب وتوثيق عند توفر إشارات الاهتمام، أو يدخل شخصية/حدثًا بنفسه. لا يدّعي النظام أن الموضوع رائج دون إشارة قابلة للمراجعة.
2. **خطة بحث:** تنويعات الأسماء بالعربية واللغات المناسبة، الفترات الجغرافية والتاريخية، أنواع المصادر، والبحث عن المؤيد والمخالف. تُميّز المقترحات من الحقائق.
3. **اكتشاف المصادر:** فهارس الكتب والدراسات والأرشيفات المسموح بها، وفق قدراتها الفعلية. يسجل النظام اسم المصدر المفهرِس، والاستعلام، وتاريخ البحث، ونطاق النتائج والحدود والأخطاء، مع التمييز بين البيانات الفهرسية والنص الكامل.
4. **حالة الوصول:** لكل مصدر حالة مثل نص متاح، سجل فهرسي فقط، يحتاج اشتراكًا، نسخة أضافها المستخدم، غير رقمي، أو تعذر الوصول. تعرض بيانات المصدر وخيارات الوصول المشروعة؛ لا يدّعي البرنامج قراءة محتوى لم يفتحه.
5. **استخراج المصادر المتاحة:** بعد اكتشاف المصدر، يحاول البرنامج استخراج المادة التي يمكن الوصول إليها واستخدامها وفق شروط الجهة وحالة الترخيص. يُسمح للمستخدم بإضافة نسخة يحق له استخدامها عند تعذر الوصول، لكن ذلك مسار بديل وليس اشتراطًا لبناء مكتبة يدوية. الملف المصور يحتاج OCR وقد يخطئ، ولا يُفترض أن كل صيغ PDF المحمية قابلة للاستخراج. لا تُرفع الملفات تلقائيًا إلى GitHub أو خدمات خارجية.
6. **استخراج ومراجعة الأدلة:** ربط كل ادعاء بمصدر أو أكثر وموضع محدد والنص المنقول عند توافره، مع حفظ وجهة النظر المخالفة والسياق ومستوى الثقة وأسباب المراجعة. لا يصير الادعاء صحيحًا لمجرد وجود استشهاد.
7. **استعراض الخطين الزمنيين:** ترتيب الأحداث وفق تاريخ وقوعها، والمصادر وفق زمن تأليفها أو الرواية/الشهادة، مع عرض زمن الطبعة أو النشر الحديث كحقل منفصل. لا يُستنتج أن طبعة حديثة مصدر تاريخي حديث، أو أن المصدر الأقدم صحيح بالضرورة.
8. **الملف المعرفي:** ملخص بحثي يميز ما سُجّل عليه دليل، وما هو محل خلاف، وما لا يمكن التحقق منه، وقائمة ثغرات البحث والمصادر غير المتاحة. التحديثات اللاحقة مؤرخة ولا تعد بتغطية كل دراسة جديدة.
9. **المخرجات اللاحقة:** محاور وسيناريو مستندان إلى الملف بعد المراجعة؛ بوابة اعتماد بشرية قبل النشر، مع منع تقديم صورة مولدة كوثيقة أو إخفاء خلاف مؤثر.

## البحث الواسع عن المواد والمرئيات

الهدف البحث في أكبر نطاق متاح ومسموح، وليس وعدًا بالوصول إلى كل كتاب أو وثيقة أو صورة في العالم. تغطية كل موصل خدمة وحدودها وتاريخ آخر بحث ظاهرة؛ عدم وجود نتيجة لا يعني عدم وجود المصدر. يضاف فهرس أو أرشيف بعد مراجعة شروطه، وحدود الوصول المجاني، ووسيلة الربط المناسبة. ويجوز البدء بخطوات يدوية عندما لا يسمح المزود بربط آلي.

### الأنواع المطلوبة

- مؤلفات وطبعاتها ودراسات وبحوث حديثة، ونسخ المستخدم التي يحق له استخدامها.
- فهارس مخطوطات وصورها المتاحة، مع المؤسسة ورقم الحفظ ومعلومات النسخة والورقة ونوع الوصول؛ فهرسة المخطوط ليست قراءة له أو إثباتًا لنسبته أو تاريخه.
- الوثائق الأصلية والرسائل والخرائط والصور الأرشيفية والنقوش والنقود والقطع المتحفية والأدوات، مع بيان المؤسسة، والمرجع والموضع أو رقم الجرد عندما يتاح.
- صور الشخصيات والأماكن والمباني والأدوات، مع التمييز بين صورة موثقة للشخص أو للموضع، وتصوير لاحق أو تفسير فني أو تمثيل معاصر. لا تُعرض صورة أو بورتريه بوصفه صورة أصلية لشخصية تاريخية لمجرد التشابه أو اسم الملف.
- صور حديثة للمواقع التاريخية مع تواريخ التصوير وحدود دلالتها؛ حال المكان اليوم قد لا يمثل حاله وقت الحدث. توثيق اسم المكان وموقعه القديم والحديث والخلاف في تحديده إن وجد.

### بطاقة المادة وحالة الوصول والاستخدام

تحتوي بطاقة كل مادة، بحسب ما توفر، على العنوان والوصف والجهة الحافظة أو المنشئ والتاريخ أو نطاقه واللغة والرابط المستقر ورقم الحفظ أو الجرد والموضع، وسبب ارتباطها بموضوع البحث، وحالة التحقق، وكيفية الوصول إليها. يميز النظام صراحة بين: سجل فقط؛ معاينة؛ نص أو صورة متاحة للاطلاع؛ ملف متاح للتنزيل؛ يحتاج إذنًا أو اشتراكًا؛ نسخة خاصة يضيفها المستخدم؛ أو غير رقمي/تعذّر الوصول. قد تختلف الإتاحة مع الوقت والبلد.

تسجّل حقوق المادة وحقوق الصورة الرقمية وشروط الاستخدام والتعديل والنسبة، وهل يسمح الاستخدام التجاري، ورابط الترخيص وتاريخ الاطلاع، مع تمييز «غير معروف» عن «مسموح». المراجعة البشرية ضرورية قبل النشر. لا تعني إتاحة المشاهدة أو انتهاء حقوق مؤلف قديم تلقائيًا حق نسخ صورة رقمية أو إعادة نشر طبعة أو استخدامها تجاريًا.

إذا تعذر الوصول لمصدر مهم، تعرض البطاقة بياناته وسبل طلبه أو إعارته المشروعة أو الرجوع إلى مؤسسة حافظة أو إضافة نسخة يحق للمستخدم استخدامها. لا يتجاوز النظام الاشتراكات أو أنظمة الحماية. إذا كانت المادة مولّدة أو إعادة تمثيل، يجب وسمها بوضوح وعدم تقديمها كوثيقة أو صورة أصلية.

### ضوابط التطبيق

- يحفظ البرنامج بيانات البحث والملفات التي يختارها المستخدم محليًا في الاستخدام المحلي، ولا يرسل الكتب أو الصور الخاصة إلى أي خدمة أو يرفعها إلى GitHub تلقائيًا. عبارات البحث تُرسل للجهة الخارجية عند استخدام خدماتها ويُبيّن ذلك للمستخدم.
- تتضمن الاختبارات ملفات مغلقة أو مرخصة للاطلاع فقط، وحقوقًا غير معلومة، وبورتريهًا لاحقًا، وصورة مكان حديثة، وسجلات فهرسية دون نص؛ يجب إظهار القيود بدل إعلان التحقق أو الترخيص تلقائيًا.
- البحث والاستخراج الواسعان للكتب والصور والوثائق والمخطوطات **لم يُنفّذا بعد** في النواة الحالية؛ توفيرهما يحتاج تطويرًا واختبارًا ومراجعة حقوق كل مزود.

## التاريخ واليقين

- حفظ التاريخ كما ورد في المصدر، مع نوع التقويم والمصدر والموضع، وحفظ صيغة معيارية للترتيب فقط عندما يمكن تحديدها أو تحويلها بشكل موثوق.
- دعم السنة التقريبية أو المدى والاختلافات وعدم اليقين، مع إظهار العناصر التي لا تاريخ معروفًا لها بصورة منفصلة، وعدم اختلاق تاريخ دقيق.
- عرض التاريخ الهجري والميلادي عند توافرهما والتحقق من التحويل؛ اختلاف طرق التحويل أو روايات التاريخ لا يُخفى.
- التمييز بين تاريخ وقوع الحدث، وتاريخ الشهادة أو الرواية، وتأليف العمل، ونسخة المخطوط، ونشر الطبعة الحديثة، والاستشهاد أو البحث الحديث.

## مبدأ التثبت والذكاء الاصطناعي

- تنظيم المصادر والادعاءات والتواريخ والبحث في البيانات المتاحة يجب ألا يتطلب نموذجًا. الاقتراحات القالبية والفرز الآلي لا يعادلان بحثًا تاريخيًا عميقًا.
- Qwen اختياري للمساعدة في اقتراح المصطلحات والقراءة والتلخيص والتحليل؛ يُظهر البرنامج المواد المرسلة والنتائج كمسودات، ولا يُمنح النموذج أدوات تنفيذ أو تعديل مباشر.
- لا يصدر النظام حكمًا نهائيًا على الأحاديث أو الروايات المسندة؛ يعرض أحكام أهل الاختصاص والخلاف والمراجع. استلهام التثبت من منهج المحدثين لا يعني تطبيق شروط الحديث حرفيًا على كل المصادر والدراسات الحديثة.
- المراجعة البشرية ضرورية، لا سيما في الأحكام المتخصصة، والتحليل ومقارنة النسخ والترجمة والنصوص المستخرجة بالـ OCR.

## خطة تدريجية مقترحة

1. **أساس البحث:** ملف موضوع، إصدارات المصادر وتواريخها وحالة الوصول، والادعاءات مع مراجع متعددة ومواضعها وخلافاتها، والتواريخ غير المؤكدة.
2. **الخط الزمني المزدوج:** عرض أحداث مرتبة حسب تاريخها، ثم مصادر مرتبة حسب زمن التأليف أو الشهادة مع تمييز الطبعة والدراسات الحديثة.
3. **الاكتشاف وإدارة البحث:** مصادر عامة موثوقة وقابلة للربط قانونيًا، تسجيل الاستعلام والنتائج وتاريخها والفجوات والأخطاء وعدم التكرار.
4. **الوصول والاستخراج:** محاولة جلب المواد المسموح بها وقراءة الأنواع الممكنة، والإبلاغ عن العوائق، والسماح بإضافة نسخة مرخصة كمسار بديل؛ توثيق الصيغ والحقوق وحالات تعذر القراءة وOCR لاحقًا حسب الاختبار.
5. **المقارنة والملف المعرفي:** مقارنة المواقف والمصادر والأدلة المخالفة مع إسناد صريح؛ Qwen مساعد اختياري بعد التحقق من الإمكانات على الجهاز.
6. **السرد والترجمة والإنتاج:** تُبنى على البحث المراجع وتبقى خاضعة للاعتماد البشري.

تعتمد الأولويات التفصيلية وترتيب مصادر الربط على تجربة فعلية وموافقة المستخدم. لا تُضاف خدمات مدفوعة دون اتفاق.

## معايير قبول أولية

- تجربة موضوع يختاره المستخدم، تتضمن مصدرًا قديمًا وطبعة حديثة ودراسة حديثة وادعاءين مختلفين، دون اختلاق مصدر أو تاريخ.
- يظل خط الأحداث منفصلًا عن ترتيب المصادر؛ تُعرض التواريخ المجهولة والتقريبية والخلافات بدل إخفائها.
- عند تعذر الوصول أو الاكتفاء بسجل فهرسي، يظهر ذلك بوضوح، ولا تُعرض اقتباسات على أنها مقروءة من النص الكامل.
- كل استنتاج جوهري قابل للتتبع إلى مصادره ومواضعها أو موسوم بأنه غير محقق؛ يمكن إرفاق دليل مخالف وأسباب تقييمه.
- اختبارات لنتائج صحيحة ومضللة، ولتوقف خدمة خارجية أو توقف النموذج، ولملف محمي أو ممسوح ضوئيًا يتعذر قراءته، ولعدم تسرب المواد أو بيانات البحث الخاصة إلى المستودع العام.
- تجربة الأداء والواجهة والتثبيت أو المعاينة على جهاز Windows قبل وصف المنتج بأنه جاهز.

## الوضع الحالي

التطبيق الحالي نواة أولية تتضمن بحثًا فهرسيًا محدودًا وتنظيمًا يدويًا للمصادر والادعاءات ومسودة قالبية. لم تُنفذ بعد معظم خصائص البحث الزمني المتعدد المصادر، أو الوصول الواسع إلى الملفات واستخراجها وتحليلها. فشل بناء Windows المحمول في خطوة الاختبارات، ولم يثبت توفر رابط موقع عام؛ يجب إصلاح وسيلة التجربة بجانب تطوير البحث.
