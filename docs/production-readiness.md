# جاهزية سَنَد للاستخدام الفعلي

هذه قائمة معايير إطلاق قابلة للتحقق، وليست شهادة بأن البرنامج منتج نهائي. النطاق الحالي برنامج محلي لـWindows وموقع يعمل في متصفح واحد؛ لا توجد مزامنة أو حسابات أو خدمة متعددة المستخدمين. لا تُرفع ملفات البحث لمزود خارجي دون إجراء المستخدم والموافقة الموضحة في الواجهة.

## ما تحسن في موثوقية العمل

- الحفظ والحذف يتحققان من إصدار المشروع. إذا تغيّر المشروع في نافذة أخرى، يرفض البرنامج العملية بدل استبدال العمل؛ يمكن حفظ التعديلات الظاهرة كنسخة مستقلة ومراجعة الاختلاف يدويًا. في Windows يقارن قاعدة SQLite الإصدار والكتابة في معاملة واحدة؛ في الموقع تتسلسل التعديلات باستخدام Web Locks. أُجريت اختبارات تعارض نافذتين وحفظ متزامن وترقية سجلات قديمة واستعادة نسخة. لا تحمي هذه الآلية من تعديل قاعدة البيانات أو التخزين مباشرة أو من نافذة موقع قديمة لا تطبق الحماية؛ أغلق النوافذ القديمة عند التحديث. لا تتزامن الأجهزة.
- النسخ الشاملة اختيارية ومحدودة، ويُختبر استرجاعها؛ لا تشمل الملفات غير المرتبطة أو تغييرات غير محفوظة أو تقدم OCR الجاري. خيار التشفير يحمي ملف النسخة لا بيانات الجهاز، ولا تدقيق مستقل للتشفير. يجب اختبار الاستعادة والاحتفاظ بالأصول في مكان مستقل.
- فشل المصادر والبيانات غير الكاملة يُعرض بدل تحويله لنتائج تجريبية. بيانات Wikimedia تقيس صفحة واحدة فقط، والاقتباس المطابق لا يُثبت صحة التفسير. نتيجة النموذج تحتاج مراجعة بشرية ولا تنفّذ أوامر.

## حواجز الإطلاق التي لم تُنجز بعد

1. **معيار الاستخدام المقصود:** تحديد إن كان الإطلاق لفرد على Windows، أو لفريق، أو لموقع عام؛ عدد المستخدمين، الدعم، المنصات، وسيناريوهات الفشل المقبولة. البنية الحالية لا تقدم حسابات أو تعاونًا أو خدمات خلفية متعددة المستخدمين.
2. **تجربة على أجهزة حقيقية:** اختبار تثبيت/تحديث/إزالة وإعادة تشغيل Windows بأنواعه المستهدفة، واللغات وأذونات المجلدات والمساحة المنخفضة، وأخذ نسخ واستعادتها على جهاز آخر. بناء GitHub الآلي وتشغيله ليسا بديلًا عن ذلك.
3. **التوزيع والثقة:** اعتماد وسيلة إصدار مستقرة بدل Artifacts منتهية، توقيع رقمي لملف Windows وإجراءات تحقق من البصمات، استراتيجية تحديث وتراجع آمن، وترخيص مشروع ومعلومات اتصال للدعم والإبلاغ الأمني يحددها المالك.
4. **الأمان والخصوصية:** مراجعة مستقلة للتهديدات والتبعيات والتشفير واستيراد الملفات وPDF وحقن تعليمات النماذج؛ تقييم عزل تحليل PDF وحدود الموارد. تخزين الجهاز غير مشفر افتراضيًا؛ مفاتيح API والبيانات الحساسة لا توضع في المستودع.
5. **جودة البحث والنموذج وOCR:** تقييم بشري على مجموعة حقيقية مرخصة ومتنوعة من مصادر تاريخية عربية، بقياسات معلنة للأخطاء والاستدعاء والمواضع وتقييم OCR، واختبار نموذج محلي حقيقي على أجهزة مستهدفة. اختبارات النموذج الآلية الحالية تستعمل نموذجًا محاكى ولا تثبت فهمه أو دقة استنتاجه.
6. **الجهات الخارجية والحقوق:** تحقق من شروط الخدمات والتراخيص والحدود التجارية والتوفر المتقلب وCORS، وتحديد تجربة الإخفاق وسياسة الحصص. نجاح اختبار حي مرة لا يضمن استمرار الخدمة ولا صحة النص أو حقوق الطبعة.
7. **التشغيل والإطلاق التدريجي:** تحديد معايير نجاح، مراجعات بشرية، سجل إصدارات، دعم المستخدم، خطة التعامل مع تلف البيانات والحوادث والتراجع، وتجربة محدودة قبل توسيع الإطلاق. لا توجد حاليًا مراقبة مركزية ولا خدمة دعم مضمونة.

تُحدَّث هذه القائمة بنتائج اختبارات فعلية؛ لا تُخفى القيود أو تُستبدل البيانات الحقيقية بمحاكاة عند تعذر الوصول.
