# سَنَد ستوديو

مساحة عمل تحريرية محلية لقناة معرفية: اكتشاف أفكار، جمع مصادر، ربط الادعاءات بأدلتها، وكتابة السيناريو وتخطيط الإنتاج. الواجهة عربية، مع مساحة لنسخة إنجليزية يحررها المستخدم.

**الحالة: نسخة أولية قابلة للتجربة، وليست النظام المتكامل النهائي.** لا تنشر تلقائيًا ولا تحل محل الباحث أو المراجع المتخصص.

## نسخة المتصفح والهاتف

توجد نسخة أولية ثابتة في جذر المستودع، ويمكن تشغيلها على GitHub Pages بعد تفعيل Pages على فرع العمل. بياناتها تبقى في متصفح الجهاز ولا تتزامن تلقائيًا، ولا تتصل بـ Qwen. راجع [دليل نسخة المتصفح وحدودها وخطوات النشر](docs/browser-edition.md).

## النسخة المحمولة لـ Windows — دون تثبيت Python

يبني سير العمل `Build Windows portable app` نسخة `Sanad-Studio.exe` عند نجاحه. لتحميلها: افتح [صفحة تشغيلات البناء على فرع العمل](https://github.com/kabiwork198-alt/sanad/actions/workflows/windows-portable.yml?query=branch%3Aarena%2F592bf7be-sanad)، واختر تشغيلًا ناجحًا، ثم حمّل ملف **Sanad-Studio-Windows** من قسم **Artifacts**. قد يتطلب GitHub تسجيل الدخول لتنزيله، وتنتهي صلاحيته بعد 30 يومًا.

فك الضغط وافتح `Sanad-Studio.exe`؛ يُفتح التطبيق محليًا في المتصفح، واترك نافذة البرنامج مفتوحة. لا يتطلب تشغيل هذه النسخة تثبيت Python أو Qwen. الملف غير موقّع رقميًا وقد يُظهر Windows تحذيرًا؛ تحقّق من مصدر الملف ولا تُعطّل الحماية لمجرد تجاهل التحذير.

تحفظ النسخة المحمولة بياناتها في `%LOCALAPPDATA%\SanadStudio` وليس في مجلد الملفات المؤقتة. إن استخدمت النسخة السابقة عبر Python، صدّر نسخة احتياطية منها واستوردها من النسخة المحمولة لنقل البيانات. قبل أي تحديث أو نقل للجهاز، صدّر نسخة احتياطية واحتفظ بها في مكان آمن.

## التشغيل من الشيفرة على Windows

1. ثبّت Python 3.9 أو أحدث من [python.org](https://www.python.org/downloads/windows/)؛ يُنصح بتفعيل إضافة Python إلى PATH أثناء التثبيت.
2. نزّل المستودع من GitHub باستخدام **Code → Download ZIP**، ثم فك ضغطه في مجلد تملك صلاحية الكتابة فيه. أو استنسخه باستخدام Git.
3. افتح الملف `start-windows.bat` بالنقر المزدوج. تفتح واجهة البرنامج في متصفحك على `http://127.0.0.1:8765/`. إذا لم تُفتح تلقائيًا، افتح هذا العنوان بنفسك.
4. اترك نافذة البرنامج مفتوحة أثناء الاستخدام. اضغط **حفظ المشروع** عند إدخال التغييرات. لإيقاف الخادم، أغلق النافذة أو اضغط Ctrl+C فيها.

بديل من موجّه الأوامر داخل مجلد المشروع:

```bat
py -3 -m sanad.app
```

لا يحتاج البرنامج إلى حساب أو نموذج ذكاء اصطناعي لوظائفه الأساسية. عند التشغيل من الشيفرة تحتاج قراءة PDF النصي إلى تثبيت المكتبة المجانية `pypdf` عبر `py -3 -m pip install -r requirements.txt`؛ أما النسخة المحمولة فتضمها. قراءة TXT/MD لا تحتاجها. إذا كان المنفذ 8765 مشغولًا، أغلق البرنامج الذي يستخدمه ثم أعد المحاولة. نجحت اختبارات آلية على Windows وفتح الواجهة في بيئة البناء؛ ما زالت التجربة على جهازك وخدمات الإنترنت مهمة، فأخبرنا بأي مشكلة.

[حالة كل مصدر وما قد يتطلبه من صلاحيات](docs/source-access.md).

## ما الذي يتوفر الآن؟

- **نتائج MinerU متعددة الصفحات:** من «المصادر» استورد ملف `middle_json` لملف PDF عالجته خارج سَنَد بـMinerU 4؛ يُحفظ النص ورقم صفحة PDF لكل نتيجة مع بصمة JSON، ويمكن تسجيل بصمة الأصل الاختيارية. سَنَد لا يشغّل MinerU ولا يضمن مطابقة الأصل أو دقة العربية، وقد يتجاهل الجداول والصور والمعادلات. [خطوات وحدود الاستخدام والاختبار](docs/mineru-research-assessment.md).

- بعد اختيار سجل من مكتبة قطر الرقمية يدويًا وإضافته للمصادر، يمكن البحث في فهرس صفحات ذلك السجل عبر IIIF، وإظهار روابط صور الصفحات المحتملة. هذه ميزة تجريبية: تعذر الاتصال المباشر في اختبار Chromium وفي فحص Windows (HTTP 403)، فاستخدم بحث السجل على موقع المكتبة عند التعذر. ليست بحثًا شاملًا ولا اقتباسًا؛ راجع صورة الصفحة والحقوق.
- بحث في ويكي مصدر الإنجليزية والفرنسية، مع تحميل النص المعروض لصفحة مختارة والبحث فيه محليًا، ويدعم ذلك العربية أيضًا. قد يكون النص مضمّنًا من صفحات أو قوالب أخرى، وقد تتغير بعد مراجعة الصفحة؛ راجع الطبعة والترجمة والصورة والحقوق. لا تترجم عبارة البحث تلقائيًا.
- في Windows: بحث اختياري عبر MCP الرسمي لأرشيف الإسكندرية، مع إمكانية حفظ نبذة عامة لمقال والبحث فيها بعد الموافقة. النص الكامل قد يتطلب دخولًا في موقع الأرشيف؛ راجع حقوق كل مادة. الأرشيف مستقل عن مكتبة الإسكندرية.
- بحث اختياري في نصوص تراث عبر MCP وفتح صفحة واحدة مختارة بعد الموافقة؛ نجح في اختبار Windows. رفض الخادم أصل موقع سَنَد في اختبار المتصفح (HTTP 403)، وقد يتعذر الاتصال منه. راجع النص والطبعة والحقوق؛ هذه خدمة تراث وليست الشاملة أو الدرر.
- في نسخة Windows: بحث اختياري عبر خدمة الشاملة MCP الرسمية وفتح جزء من صفحة واحدة بعد الموافقة على شروط الجهة. لم ينجح اتصال المتصفح المباشر بسبب CORS؛ المعاينة ليست استشهادًا وحقوق كل طبعة محفوظة.
- بعد إضافة سجل Internet Archive إلى المصادر، يمكن محاولة تحميل ملف OCR عام واحد حتى 16 ميجابايت والبحث فيه محليًا بعد الموافقة. المواد المقيّدة أو للإعارة والملفات الخاصة مستبعدة؛ النص قد يخطئ، والإتاحة لا تثبت حق الاستخدام. طابق الاقتباس مع الأصل.
- **Windows: البحث داخل مجموعة OpenITI الأساسية**: بعد الموافقة تُنزّل نسخة 2025.1.9 الرسمية من Zenodo (2.86 جيجابايت)، وتُتحقق بصمة MD5 المنشورة وحجم الملف؛ يمكن إيقاف التنزيل واستكماله إذا دعمت الجهة طلب النطاق. يبحث البرنامج محليًا في النصوص داخل الأرشيف المضغوط دون فك المجموعة أو إرسال العبارة للإنترنت. يقرأ الملفات بالتتابع، وقد يستغرق البحث وقتًا طويلًا؛ يعرض حتى 100 مقتطف لكل صفحة وحدّ مقتطفين لكل نسخة؛ الصفحة التالية تعيد المسح، ويبين الملفات المتخطاة أو النتائج المحدودة. يمكنك ربط مقتطف غير مفحوص أو حفظ نص نسخة حتى 16 ميجابايت. المجموعة ليست كل الطبعات أو المصادر، ورخصتها CC BY-NC-SA 4.0 تقيد الاستخدام التجاري؛ راجع الطبعة والحقوق. رقم السطر تقريبي وليس صفحة مطبوعة.
- بحث اختياري في فهرس OpenITI 2025.1.9 بعد الموافقة على تنزيل نحو 12 ميجابايت؛ يطابق العناوين والمؤلفين محليًا، ثم يمكن تحميل نص نسخة محددة حتى 16 ميجابايت والبحث فيه على الجهاز بعد الموافقة. قد لا يكون النص متاحًا، وأرقام الأسطر ليست صفحات الطبعة. الإصدار مرخص CC BY-NC-SA 4.0 ويقيد الاستخدام التجاري؛ افحص كل نص وطبعة.
- **البحث متعدد المحاور:** ينشئ الباحث افتراضيًا العبارة الأصلية و11 عبارة قالبية للتسلسل الزمني والجغرافيا والسياسة والشخصيات والمصادر، ويعرضها للموافقة قبل البحث الخارجي. يرسل الأصل إلى الجهات المدعومة، والتفريعات إلى عدد محدود من الفهارس؛ لا تبحث كل عبارة في كل جهة. ينفذ حتى أربع محاولات متوازية، ويسجل الإخفاقات ويوقف طلبات الجهة عند HTTP 429، ويجمع الروابط المتطابقة مع حفظ جهة وعبارة كل اكتشاف. يمكن تجربة العبارة الأصلية وحدها أو إعداد ملخص محدود للمساعد المحلي دون إرساله تلقائيًا. هذه قوالب لا تضمن الشمول أو إثبات أي واقعة أو قراءة نص؛ راجع [التفاصيل والقيود](docs/multi-query-research.md).
- واجهة عربية متجاوبة برئيسية ومساحة مشروع ودليل مستقل للمصادر، مع تبويب «الربط اليدوي»: افتح الجهة بنفسك، وسجّل بيانات المصدر والإتاحة والحقوق، ثم اربط نسخة محلية مسموحة بالبطاقة للبحث فيها. هذه العملية لا تفعّل API ولا تتجاوز قيود الوصول.
- مشاريع محلية، بطاقة فكرة، واقتراح أسئلة وزوايا قالبية انطلاقًا من العنوان. الاقتراحات لا تدل على رواج الموضوع. يمكن تسجيل إشارات الاهتمام ومصدرها ومجالها وتاريخها وحدودها.
- بحث اختياري في YouTube باستخدام **مفتاح YouTube Data API الخاص بك**؛ تُعرض نتائج البحث فقط ولا تُحفظ تلقائيًا. الإعداد يتطلب مشروع Google وتفعيل API ويخضع للحصص والشروط. يُدخل المفتاح في صفحة البرنامج على جهازك، ولا تطلبه في المحادثة أو تضعه في GitHub. يُرسل إلى Google مع عبارة البحث ولا يخزّنه البرنامج.
- عند إضافة عمل من Open Library، اعرض طبعاته بعد الموافقة (20 سجلًا في كل صفحة، حتى 1020 سجلًا) واختر طبعة لإضافتها. إذا تضمّن سجلها معرّف Internet Archive، يمكنك محاولة تحميل OCR العام بالطريقة أعلاه. يحتفظ سَنَد بروابط العمل والطبعة والأرشيف وبيانات النشر؛ الربط فهرسي وقد يكون خاطئًا أو قديمًا ولا يثبت الإتاحة أو التطابق أو الحقوق. لا يُحمّل أي نص تلقائيًا.
- بحث اختياري في بيانات Crossref الببليوغرافية وفهرس Open Library للكتب وإضافة نتيجة كمصدر. يتطلب اتصالًا بالإنترنت؛ لا يضمن الوصول إلى النص الكامل أو تغطية المصادر التراثية العربية بصورة كافية.
- البحث في حتى 20 ملفًا محليًا مرتبطًا بمصادر في المشروع بالعبارة نفسها، مع عرض النجاح أو تعذر الفحص لكل ملف. يمكنك ربط المقتطفات بادعاء موجود كمقارنات «غير محسومة»؛ لا يقرر سَنَد صحة الأدلة أو اتفاقها. النتائج محدودة بـ12 لكل ملف، وفحص PDF حتى 300 صفحة.
- من «المصادر»، استخرج نص صورة PNG/JPEG أو نطاق حتى 300 صفحة PDF متتابعة من ملف مسموح غير محمي حتى 20 ميبيبايت، باستخدام OCR محلي عربي أو إنجليزي مضمّن. تعرض العملية التقدم وتسمح بالإيقاف بعد الصفحة الحالية والاحتفاظ بالجزء المكتمل؛ تسجل صفحات الفشل أو الخلو من النص وموضع كل مقتطف وبصمة الأصل. المعالجة قد تطول، ولا تحفظ التقدم أثناء التشغيل أو تحفظ الأصل؛ أبقِ الصفحة مفتوحة، واحفظ المشروع واحتفظ بالأصل بعد الاستخراج. راجع الحقوق ودقة النص والطبعة، خصوصًا المخطوطات. اختبار التحقق شمل PDF مصورًا اصطناعيًا من 12 صفحة وليس كتابًا تراثيًا كاملًا.
- تُفحص بصمة الملفات المحلية قبل البحث والتصدير، ويُحفظ الملف في Windows بصورة ذرّية لتجنب ظهور ملف ناقص عند الإضافة المتزامنة. إن تغيّرت بيانات أثناء عملية الحفظ، تبقى حالة «تغييرات غير محفوظة» ظاهرة حتى تحفظها مجددًا؛ لا يحل ذلك محل النسخ الاحتياطي المنتظم.
- إضافة ملفاتك المسموح بها محليًا بصيغ PDF نصي وTXT وMD حتى 20 ميجابايت للملف، والبحث داخلها، ثم إضافة مقتطف إلى الادعاءات بوصفه غير محقَّق. البحث لا يقرأ الملفات المصورة دون OCR ولا يتجاوز تشفير PDF. النص المستخرج آليًا قد يتضمن أخطاء ويجب مطابقته بالأصل.
- خط زمني للأحداث، وخط مستقل للمصادر مرتبان بالسنة الميلادية التي تدخلها بعد مراجعتها؛ لا يحوّل البرنامج الهجري ولا يحدد التاريخ تلقائيًا، والمجهول يظهر في النهاية.
- لصفحة نتيجة من ويكي مصدر العربية: أضفها إلى المصادر ثم اضغط «تحميل نص صفحة ويكي مصدر والبحث فيه»؛ بعد الموافقة يجلب البرنامج نسخة خام واحدة مع رابط مراجعتها الثابت ويخزنها محليًا للبحث. قد تكون صفحة فهرس أو جزءًا فقط، وقد تحتوي قوالب ويكي غير مفككة. رقم السطر ليس صفحة الطبعة، ويجب التحقق من النسخة والترخيص قبل الاستشهاد أو النشر.
- يُبحث في OpenAlex دون حساب أو مفتاح وبحصة مجانية مشتركة محدودة؛ قد يتعذر مؤقتًا عند نفادها. لا يُفعل البرنامج اشتراكًا مدفوعًا. DOAJ وOpenAlex فهارس، وليس نجاح البحث إثباتًا لقراءة النص الكامل.
- تسجيل المصادر والادعاءات وحالات مراجعتها، وفحص اكتمال الحقول للتنبيه إلى نواقص الإشارات والادعاءات. لا يسمح البرنامج بحفظ ادعاء بحالة «مدعوم» دون ربطه بمصدر وموضع، لكن **الفحص تنظيمي ولا يثبت صحة الدليل**.
- محرر للمخطط والسيناريو والنسخة الإنجليزية، وقائمة للمشاهد والترخيص وملاحظات المراجعة. يمكن إنشاء مسودة قالبية من الادعاءات التي صنفتها أنت «مدعوم» مع مصادرها ومواضعها، ثم مراجعتها وتحريرها وتصدير النص العربي. يستبعد القالب الادعاءات الأخرى وينبه إلى عددها؛ يجب عدم إخفاء خلاف مؤثر. لا يترجم البرنامج تلقائيًا دون نموذج.
- نسخة احتياطية JSON شاملة للمشاريع المحفوظة وملفات المصادر المرتبطة بها، واستيرادها كنسخ جديدة في الموقع أو Windows. الحد 100 مشروع و100 ملف مرتبط بإجمالي 64 ميبيبايت، و5 ميبيبايت لبيانات المشاريع. تتحقق من بصمة الملفات؛ لا تشمل ملفات غير مرتبطة أو تغييرات غير محفوظة، وليست مشفرة. النسخ القديمة لا تتضمن الملفات. احتفظ بالأصول وانسخ مجلد البيانات واختبر الاسترجاع دوريًا.
- مساعد Qwen اختياري عبر LM Studio: حمّل نموذجًا محليًا وشغّل الخادم على `127.0.0.1:1234`، ثم اكتب اسمه وطلبك في تبويب المساعد. لا يستعمله البرنامج إلا عند الإرسال اليدوي؛ يمكن تجهيز طلب من ملف الادعاءات ومراجعته قبل الإرسال. الاستجابة مسودة للنسخ والمراجعة ولا تنفذ أوامر أو تعدل البيانات. تأكد أنك اخترت نموذجًا محليًا وليس نموذجًا سحابيًا في LM Studio.

## حدود مهمة

- اقتراح الأسئلة هنا يعتمد على قوالب عامة من العنوان، واكتشاف الموضوعات يجمع نتائج وملاحظات؛ لا يضمن العثور على الموضوعات الرائجة أو نجاح الفيديو. بيانات Google Trends تدخل يدويًا، وهي مؤشرات نسبية وليست عدد عمليات البحث.
- لا تتوفر بعد ترجمة تلقائية مستقلة، أو OCR موثوق دون مراجعة لكل كتاب مصوّر، أو تنزيل النصوص الكاملة تلقائيًا من كل الجهات، أو ربط جميع المكتبات والمخطوطات المتخصصة، أو تحليل منافسين شامل، أو توليد فيديو وصوت، أو آلية نشر. لا يُعد المشروع كاملًا من جهة هذه الوظائف.
- لا يُحكم على صحة المعلومات من مجرد نتائج البحث أو رد النموذج. تُراجع الاقتباسات والأدلة والخلافات والحقوق بشريًا قبل النشر. المسودة ليست سيناريو نهائيًا وقد تحتاج إعادة مراجعة إذا تغيّرت مصادرها أو الادعاءات بعدها؛ لا يُفحص نص السيناريو تلقائيًا للتأكد من أن جميع ادعاءاته موثقة.
- الاتصال بالبحث الخارجي يرسل عبارة البحث إلى الجهة المعنية بعد تأكيدك. وظيفة LM Studio ترسل الطلب الذي تكتبه إلى الخادم المحلي فقط؛ لا تُرسل له ملفات المشروع تلقائيًا.
- عند تشغيل الشيفرة، تُحفظ قاعدة البيانات والملفات المضافة داخل `.sanad-data` في مجلد التطبيق، وهو مستثنى من Git. في النسخة المحمولة تُحفظ البيانات والملفات في `%LOCALAPPDATA%\SanadStudio`. المستودع عام: لا ترفع إليه مصادر خاصة أو نسخًا احتياطية أو مفاتيح. لا تحذف مجلد البيانات عند تحديث البرنامج دون أخذ نسخة احتياطية أولًا.
